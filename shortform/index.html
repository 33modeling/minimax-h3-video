          • 파일을 한꺼번에 놓기 — JSON·영상·그림·음악·zip을 같이 놓으면 알맞은 칸에 나눠 넣어요. 칸마다 직접 놓거나 고를 수도 있어요.
          • 1. 작업 JSON — 무엇을 만들지 적은 설정 파일. 직접 고치거나 Claude가 쓰게 할 수 있어요. 동화책 콘티·동화책 만들기 JSON도 돼요.
          • 2. 내 영상·그림·음악 — JSON이 이름으로 가리키는 영상·배경음, 이야기의 쪽 그림. 파일마다 어디에 쓰이는지 붙어요.
          • 3. 첫 장면 그림 · 4. 참고 자료 — AI 영상의 시작 그림과 인물·동작·목소리 참고. 넣으면 JSON에 이름이 들어가요.
          • 모양·화질 — 템플릿 카드, 가로 영상 맞춤, 해상도, fps, 품질.
          • 미리보기·만들기 — 저해상도 미리보기, 진행률과 남은 시간, 취소, 결과 내려받기.

          자주 겪는 문제

          • 서버에 연결하지 못함(CORS) — 서버를 h3video web --cors-origin https://33modeling.pages.dev로 띄워 이 페이지 주소를 허용하세요.
          • 원격 GPU 서버 — https 페이지는 다른 PC의 http 주소를 막아요(혼합 콘텐츠). ssh -L 8790:localhost:8790 사용자@서버로 터널을 열고 http://localhost:8790을 쓰세요.
          • "WebCodecs가 없어 실시간 녹화" — 오래된 브라우저예요. 최신 크롬·엣지에서 열면 MP4(H.264+AAC)로 빠르게 만들어요.
          • 영상 코덱을 풀지 못함 — HEVC·ProRes 같은 영상은 브라우저가 못 풀 수 있어요. H.264 MP4로 바꿔 넣으세요.
          • 파일 이름이 안 맞음 — JSON의 base·sources·bgm 이름과 2번 칸의 파일 이름이 같아야 해요(폴더는 무시). 빠진 파일은 빨간 칸으로 보여요.
          • zip이 안 열림 — 암호가 걸렸거나 아주 큰(4GB 넘는) zip은 못 열어요. 풀어서 파일들을 넣으세요.
