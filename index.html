    자주 겪는 문제

    • 서버에 연결하지 못함(CORS) — 서버를 h3video web --cors-origin https://33modeling.pages.dev로 띄워 이 페이지 주소를 허용하세요.
    • 원격 GPU 서버 — https 페이지는 다른 PC의 http 주소를 막습니다(혼합 콘텐츠). ssh -L 8790:localhost:8790 사용자@서버로 터널을 열고 http://localhost:8790을 쓰세요.
    • "WebCodecs가 없어 실시간 녹화" — 오래된 브라우저입니다. 최신 크롬·엣지에서 열면 MP4(H.264+AAC)로 빠르게 만듭니다.
    • 영상 코덱을 풀지 못함 — HEVC·ProRes 같은 영상은 브라우저가 못 풀 수 있습니다. H.264 MP4로 바꿔 넣으세요.
    • 파일 이름이 안 맞음 — JSON의 base·sources·bgm 이름과 2번 칸의 파일 이름이 같아야 합니다(폴더는 무시).
